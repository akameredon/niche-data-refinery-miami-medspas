# Data

- `clinics.json` — 80 structured Miami med spa records (the core dataset for the API, MCP tools, and dashboards).
- The Excel master (`Miami_MedSpas_Data_Refinery_v1.xlsx`) is binary and kept out of git; download from releases or the original build artifacts if needed.
- `previous_clinics.json` is produced by `scripts/refresh_check.py --snapshot` for change detection.
